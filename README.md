# Campus Navigation System

## Project Description

Campus Navigation System is a frontend web application developed using HTML, CSS, and JavaScript. The system helps users locate examination halls, classrooms, laboratories, libraries, placement cells, and other campus facilities efficiently.

Users can search locations using hall ticket numbers, classroom names, laboratory names, or facility names and instantly receive navigation information.

## Features

- Search Exam Hall locations
- Search Classroom locations
- Search Laboratory locations
- Search Library and Placement Cell
- Case-insensitive search support
- Space-insensitive search support
- Dynamic location display
- Empty input validation
- Enter key search functionality
- User-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript
